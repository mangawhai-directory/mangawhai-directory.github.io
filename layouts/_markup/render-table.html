{{- /* render-table — markup for tables written in markdown (advertise, terms, …). Goldmark emits a bare , which the prose container in layouts/_default/single.html has no rules for, so tables rendered with no padding and no rules and the headers ran together. This hook adds: · a scroll wrapper, so a wide table scrolls instead of crushing; · data-label on every cell, carrying its column heading, so under 640px each row can restack as a small labelled card (see .prose-table in assets/css/main.css); · data-row-head on the first cell, which names the row rather than holding a value, so it can head that card. Cell .Text is already-rendered inline markup, so bold prices survive. */ -}} {{- $labels := slice -}} {{- with .THead }} {{- range (index . 0) }}{{ $labels = $labels | append (.Text | plainify) }}{{ end }} {{- end -}} {{- /* The wrapper scrolls but is deliberately not a focusable role="region": the card layout means these tables never overflow, so that would only add dead tab stops. A table wide enough to genuinely scroll on desktop should get the focusable treatment then, not speculatively now. */ -}}
{{- with .THead }} {{- range . }} {{- range . }} {{- end }} {{- end }} {{- end }} {{- with .TBody }} {{- range . }} {{- range $i, $cell := . }} {{ $cell.Text }} {{- end }} {{- end }} {{- end }}

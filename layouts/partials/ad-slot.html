{{- /* ad-slot partial — renders an advertising slot. If config has an image, shows the ad as a click-through (with optional mobile companion). Otherwise renders a subtle placeholder that displays the slot's package, size and price. Args (dict): slot — config path under hugo.Data.ads (e.g. "home", "category.cafes-restaurants-bars") w — desktop intrinsic width in px (e.g. 1152, 540) h — desktop intrinsic height in px (e.g. 300, 350) wm — mobile intrinsic width in px (default = w) hm — mobile intrinsic height in px (default = h) label — package name shown in placeholder (e.g. "Homepage tile") price — monthly price shown in placeholder (e.g. "$250 / month") class — optional extra Tailwind classes for the wrapper id — optional fragment id for the wrapper, so the slot can be deep-linked (the advertise page's "What is this?" examples scroll to it). Keep it stable: data/rates.yaml names it. heading — optional; true renders the small "Advertisement" label above the slot (the home page uses it). See the note on the label below. Both the ad and the placeholder carry data-ad-* attributes; ad-tracking.html reads them to emit GA4 ad_engagement / ad_view events. See data/ads.yaml for the `id` and `advertiser` fields behind them, and for how a slot's bookings are laid out by month. Aspect ratio is applied responsively: aspect-[wm/hm] below `lg`, aspect-[w/h] from `lg` and up. If the wrapper has explicit lg:h-[Hpx], that height takes precedence over the aspect-ratio at desktop. An ad with no mobile creative is shown at its own ratio at every width: the wrapper gets an inline aspect-ratio read from the image file (falling back to w/h when the file cannot be measured, e.g. an SVG or a remote URL) and height:auto. Inline beats the caller's aspect-square and its fixed desktop height, so a lone banner scales down on phones and a lone square stays square on desktop, instead of object-cover cropping either. An inline style rather than a class because the ratio is built at render time and Tailwind would never emit it. images.Config reads the static path, so the ratio can never drift from the file; fileExists guards it because a missing path would fail the build. A lone creative is also capped at $soloMaxH tall so a square does not tower over the page header on desktop: because the width is what the caller sets, the cap is applied as a max-width of maxH × ratio (a max-height alone would break the ratio), so the box gets narrower than the slot and keeps its shape. A lone creative is never drawn wider than its own width either, so a 500x250 category-size banner booked into the 1152-wide home slot shows at 500x250 instead of being stretched to fill the slot (the 400px cap alone would let a 2:1 banner reach 800 wide). Its own width is the booking's `width` when set, else the file's pixel width. `width` exists because creatives are often supplied at 2x for sharp screens (go-gas's 500x250 is a 1000x500 file), and the file cannot say which it is; capping at 1000 would defeat the point. The cap is the smaller of the two figures, and the box is centred (mx-auto) in whatever room is left. In the category slot a lone 500x250 banner fills the 500-wide header slot at xl as before; between lg and xl, where the header stacks, the old 800px cap overrode the caller's max-w-[500px] and stretched it, and now it stays at 500 like the slot it was made for. A lone square is still held by the 400px cap. The caller's mx-auto is not repeated, and its xl:mx-0 still wins at xl because the variant comes later in the stylesheet. The "Advertisement" label (heading) is rendered here rather than by the caller because it has to sit on the creative's left edge, and only this partial knows how wide a lone creative ends up. For a lone creative the label and the aside share a frame that carries the same max-width and mx-auto, so the label moves in with the creative; otherwise (a desktop and mobile pair, or the placeholder) there is no frame and the label is rendered exactly where the caller's wrapper used to put it, so the caller's wrapper keeps doing the sizing. */ -}} {{- $slot := .slot -}} {{- $w := .w -}} {{- $h := .h -}} {{- $wm := .wm | default $w -}} {{- $hm := .hm | default $h -}} {{- $label := .label | default "" -}} {{- $price := .price | default "" -}} {{- $extra := .class | default "" -}} {{- /* Walk the dotted slot path through hugo.Data.ads to the slot, then pick the booking that covers the month this build runs in.
